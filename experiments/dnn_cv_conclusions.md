## Итоговая проверка DNN на пяти разбиениях

Проведено 10 обучений: one-hot MLP `[24]` без Dropout и EmbeddingMLP `[24, 32, 16, 8]` с размером вектора 2 и Dropout 0.15. Везде ReLU, Adam, LR 0.003, batch size 16, seed обучения 42, без BatchNorm, scheduler и весов классов.

Внешние фолды сформированы StratifiedKFold (5, shuffle=True, random_state=42). Внутри каждого оставшиеся данные разделены стратифицированно 80/20 (random_state=42). Предобработка обучалась только на внутреннем train; внутренняя validation выбирала checkpoint по обычной BCE. Внешний фолд использован только после восстановления весов. Каждый из 891 пассажиров получил ровно одно внешнее предсказание от каждого кандидата.

| Модель | Средняя Accuracy | Стандартное отклонение Accuracy | Средний BCE loss | Средний ROC-AUC |
|---|---:|---:|---:|---:|
| One-hot `[24]` | 81.82% | 1.55 п.п. | 0.42323 | 0.86670 |
| Embedding `[24,32,16,8]` | **83.05%** | 3.39 п.п. | **0.42165** | **0.86752** |

| Внешний фолд | One-hot Accuracy | Embedding Accuracy |
|---|---:|---:|
| 1 | 84.36% | 84.36% |
| 2 | 80.34% | 80.34% |
| 3 | 80.90% | 78.65% |
| 4 | 81.46% | 86.52% |
| 5 | 82.02% | 85.39% |

**Выбор:** EmbeddingMLP `[24,32,16,8]`, размер Embedding 2, Dropout 0.15. Правило зафиксировано до запусков: максимальная средняя внешняя Accuracy; при равенстве — меньший средний loss, затем меньше параметров. Выбранная конфигурация записана в `config.yaml`; one-hot остаётся контрольным вариантом.

- Преимущество средней Accuracy составляет **1.24 процентного пункта**. По объединённым внешним предсказаниям Embedding дал **740/891** правильных ответов, one-hot — **729/891**: чистый прирост 11 ответов.
- Embedding выиграл 2 фолда, проиграл 1, на 2 Accuracy совпала. Его разброс между фолдами больше; небольшое превосходство средних loss и ROC-AUC не доказывает устойчивого преимущества на любых данных.
- ROC-AUC объединённых внешних предсказаний: Embedding **0.86461**, one-hot **0.86402**. Он отличается от среднего ROC-AUC фолдов, поскольку объединяются оценки пяти разных обученных моделей.
- Число параметров зависит от категорий, найденных внутри train-фолда: **1765–1767** для Embedding и **337–361** для one-hot. Словари не расширялись по внешним данным.
- Кандидаты ранее подбирались на этом наборе данных. Эта проверка оценивает зависимость от разбиения, но не является полностью независимым финальным тестом. Использован один seed обучения, сравнивались две полные конфигурации; преимущество нельзя приписать отдельно Embedding или глубине.
